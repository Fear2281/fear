# Как вывести Encore в Интернет

Нужны **VPS с Ubuntu 24.04**, доступ по SSH и **собственный домен**. GitHub хранит исходники; GitHub Pages не запускает сервер C#.

## 1. Подготовь сервер

В панели хостинга создай VPS (рекомендуется от 2 ГБ RAM). У домена создай DNS-запись **A → IP сервера**. Если добавляешь AAAA, она должна указывать на рабочий IPv6 сервера. В firewall хостинга разреши входящие TCP 80 и 443; SSH 22 оставь доступным для своего IP.

Подключись из терминала компьютера:

```sh
ssh YOUR_USER@YOUR_SERVER_IP
```

Установи Docker Engine и Compose plugin по официальной инструкции для Ubuntu:
https://docs.docker.com/engine/install/ubuntu/

Проверь:

```sh
docker --version
docker compose version
```

Если Docker требует root, используй `sudo docker ...`. Не нужно устанавливать .NET на VPS: он внутри контейнера.

## 2. Скачай проект

```sh
sudo apt update
sudo apt install -y git
git clone https://github.com/Fear2281/fear.git
cd fear
cp .env.example .env
chmod 600 .env
nano .env
```

В редакторе замени DOMAIN на **свой домен без https://**. В ENCORE_DJ_PASSWORD впиши свой длинный пароль (это пароль пульта диджея, не пароль GitHub). Сохрани Ctrl+O, Enter; выйди Ctrl+X. Не отправляй пароль в чат и не добавляй `.env` в Git.

## 3. Запусти

```sh
sudo docker compose up -d --build
sudo docker compose ps
sudo docker compose logs --tail=50
```

Открой **https://ТВОЙ_ДОМЕН**. Caddy получает HTTPS-сертификат автоматически, когда домен указывает на VPS, порты доступны и сервер имеет выход в Интернет. Это может занять некоторое время. Проверь каталог, выбор столика и вход диджея с установленным паролем.

Проверка готовности:

```sh
curl --fail https://ТВОЙ_ДОМЕН/api/health
```

Ожидается `status: ok`, `modules: 2`. Если QR не открывает сайт на телефоне, проверь DOMAIN, DNS, HTTPS и Интернет на телефоне. На сервере QR автоматически содержит домен из `ENCORE_PUBLIC_URL`.

## 4. QR-код

Нажми **«QR входа»** на сайте → **«Скачать QR»**. Распечатай: сканирование открывает сайт, где гость выбирает один из 12 столиков. В пульте есть индивидуальные QR: они подключают конкретный столик сразу. Общий QR и индивидуальные коды начинают работать публично после размещения сайта по указанному адресу.

## 5. Обновления и данные

```sh
git pull --ff-only
sudo docker compose up -d --build
```

Заявки и настройки сохраняются в Docker volume `encore-data`; ключи авторизации — в подкаталоге `keys`. **Не выполняй `docker compose down -v`**, если хочешь сохранить данные. Не запускай второй экземпляр app на том же JSON-файле. Масштабирование и большая нагрузка потребуют БД.

Пример ручной резервной копии (кратко останавливает приложение):

```sh
sudo docker compose stop app
sudo docker compose run --rm --no-deps --entrypoint tar app -C /data -czf - . > encore-backup.tar.gz
sudo docker compose start app
chmod 600 encore-backup.tar.gz
```

Храни копию вне VPS: в ней находятся токены столиков и ключи авторизации. Восстанавливать следует на остановленном app после проверки копии; текущая инструкция не является проверенным сценарием восстановления.

## Что проверено

C#-сборка, API и браузерные сценарии проверяются локально. Факт размещения на вашем VPS, выдача публичного HTTPS-сертификата и сканирование реальным телефоном могут быть проверены только после настройки вашего сервера. Перед внешним показом убедитесь, что вы запускаете Production и используете собственный пароль.
